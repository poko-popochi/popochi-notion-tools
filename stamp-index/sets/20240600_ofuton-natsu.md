# おふとん大好き_夏（40枚）

- 発売：2024-06
- 画像：`01_LINEスタンプ/2024/202406おふとん大好き_夏/images_instagram/NN.png`（**1080×1350でそのまま使える**）
- キャラ：**おじいちゃん口調のぽぽち**（全40枚とも**ふとんに入ったまま**）
- 芸風：**「〜のじゃ」「〜かのう」の老人口調**で、ふとんから出ない。⭐**構図が40枚とも同じ（ふとん）で、布団の色だけが水色→緑→青と変わる**。夏の不調（夏バテ・低気圧・熱中症・夏風邪）の声かけが濃い
- ⚠口調が独特なので、**本文も「〜のじゃ」に寄せるか、絵だけ借りるか**を決めてから使う
