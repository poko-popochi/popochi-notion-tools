## やり方
1. タグ編集の画面を開く。アイテムIDがわかっていれば直接 `https://creator.line.me/my/6prAh0DXp4qpDOM7/sticker/<アイテムID>/tag#/001`。わからなければ マイページ → アイテム管理 → 「ぱぴちのダジャレスタンプ」→ 「タグ設定」タブ → 001の行のリンク
2. 001から順に、表のタグを候補リストから選ぶ。001の横の「＞」で次の番号へ進める。1個ずつ進める
3. この画面は保存ボタンがなく、タグを1個選ぶたびに自動保存される（右上に「保存しました」）。最初の1個（001）が終わったら画面のスクショを見せて止まる。ぽこがOKを出したら残りを進める（違っていたら×で外せば戻る）
4. 10個ごとにページを読み込み直して、保存されているかを確かめ、何番まで終わったかを報告する
5. すでにタグが入っている番号があっても消さない（ぽこが手で途中まで入れていることがある）。表との差分だけ足す

## 守ること
- 表にあるタグだけを付ける。足りなく見えても、表にないタグは足さない（9個まで埋めない）
- 番号と絵柄がずれていないか、毎回スタンプの文字（2列目）と画面の絵を見比べる。合わなければそこで止まってぽこに聞く
- 候補リストに見つからないタグがあったら、飛ばしてメモしておき、最後にまとめて報告する
- 「リクエスト」「申請」「販売開始」など、審査や公開に進むボタンは押さない。タグの保存までで止める
- ログイン画面やCAPTCHAが出たら止まってぽこに聞く

## 最後に
全部終わったら、入れられなかったタグ・気になったことを一覧で報告して終わり。
