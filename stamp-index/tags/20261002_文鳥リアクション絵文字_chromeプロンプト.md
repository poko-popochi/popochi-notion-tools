LINE Creators Market（https://creator.line.me/）で、絵文字「文鳥さんのリアクション絵文字」のタグを入力してください。Chromeはぽこのアカウントでログインずみです。

## タグ表
~/Projects/SNS-notion-tools/stamp-index/tags/20261002_文鳥リアクション絵文字_タグ表.tsv
（1列目=番号001〜040、2列目=絵文字の文字、3列目=タグを「／」区切り。4列目のメモは入力しない）

## やり方
1. マイページ → アイテム管理 → 「文鳥さんのリアクション絵文字」→ タグ編集の画面を開く
2. 001から順に、表のタグを候補リストから選ぶ。1個ずつ進める
3. 最初の1個（001）が終わったら、保存する前に画面のスクショを見せて止まる。ぽこがOKを出したら残りを進める
4. 10個ごとに保存して、何番まで終わったかを報告する

## 守ること
- 表にあるタグだけを付ける。足りなく見えても、表にないタグは足さない（9個まで埋めない）
- 番号と絵柄がずれていないか、毎回絵文字の文字（2列目）と画面の絵を見比べる。合わなければそこで止まってぽこに聞く
- 候補リストに見つからないタグがあったら、飛ばしてメモしておき、最後にまとめて報告する
- 「リクエスト」「申請」「販売開始」など、審査や公開に進むボタンは押さない。タグの保存までで止める
- ログイン画面やCAPTCHAが出たら止まってぽこに聞く

## 最後に
全部終わったら、入れられなかったタグ・気になったことを一覧で報告して終わり。
