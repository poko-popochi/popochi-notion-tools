# スタンプ在庫インデックス

SNSの「スタンプ絵＋ひとこと」投稿を組むための、1枚ずつの中身のデータ。
これが無いと「この文言に合う絵」を引けないので、投稿の質がここで決まる。

## 使い方
1. 投稿したい日のネタ（季節・記念日・曜日の空気）を決める
2. `sets/*.md` から**絵の内容**で合うカットを探す（文言だけで探さない。絵が語ってることのほうが大事）
3. 画像の実体＝`/Volumes/GoogleDrive/Drive/Works/Popochi works/01_LINEスタンプ/<年>/<セット>/images_instagram/<番号>.png`（1080×1080…ではなく **1080×1350の4:5・そのまま投稿できる**）

## 投稿枠の実態
- **20:00 JST（Notionの公開日 11:00Z）＝スタンプイラストの枠**。ほぼ1日おきに入っている
- 12:00 JST（03:00Z）＝告知・カレンダー・ゲームなど
- 正データ＝Notion「SNS更新LIST」／データソース `1734552d-5ffb-8122-a2b3-000b972d08d7`
- 未リリースのスタンプは**発売2〜3日前から「もうすぐリリースだよ！」の予告も兼ねて**出す運用（2026-08-26 ぽこ）
